Update these notes after each lesson: move concepts into **Covered** only after we have explained them and tried them in the project. Add your own examples and questions while revising.

## Project learning loop

1. Learn one concept and identify where it appears in the code.
2. Make a small change yourself.
3. Run the app or a focused check and explain the result in your own words.
4. Record the concept, a short example, and anything that is still unclear here.
