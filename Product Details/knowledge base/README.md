## Learning agreement

This is a guided build, not a code-generation exercise. For each small lesson:

1. We state the goal and the user-visible or technical reason for it.
2. We learn the concepts and trace the relevant flow before changing code.
3. You implement the next small task. I give hints and review first; I provide a complete solution only when you ask or are blocked.
4. We run a focused check and discuss what it proves and what it does not prove.
5. You explain the result back in your own words, then we update the learning notes.

We can move at your pace across multiple sessions. A topic is not marked covered just because code exists; you should be able to explain, change, and verify it.
